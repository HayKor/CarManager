# Car Manager App — ТЗ (черновик)

Приложение для автовладельцев, автомехаников и владельцев небольших автосервисов: учёт авто, истории обслуживания, поиск по услугам, напоминания.

## MVP — базовые функции

- **Авто**: CRUD (марка, модель, год, VIN, госномер, фото, текущий пробег)
- **Записи об обслуживании**: дата, пробег, тип услуги, стоимость, комментарий, вложения (фото чека/скан)
- **Поиск по услугам** across всех авто — фильтры: тип услуги, диапазон дат, диапазон пробега, конкретное авто
- **Отчёты**: расходы по периоду / по авто / по типу услуги, экспорт в PDF/CSV
- **Документы**: хранение документов, привязанных к авто (страховка, СТС, гарантия)

## Напоминания (регламентное ТО)

- Правило: `interval_km` и/или `interval_months` (срабатывает то, что наступит раньше)
- Источники пробега:
    - реальный ввод при добавлении записи об услуге (основной источник)
    - быстрое ручное обновление (одна кнопка на карточке авто, не гейтить вход в приложение)
    - **оценка пробега** между реальными вводами: `avg_km_per_day` по последним записям → `estimated_mileage = last_known + avg_km_per_day * days_since`
- Логика триггера: сравнивать `estimated_mileage` с `due_mileage` и текущую дату с `due_date`
    - date-based порог сработал → точное уведомление
    - km-based порог сработал по оценке → уведомление с пометкой «уточните пробег» + CTA на быстрый ввод
- Напоминания также по документам: страховка, техосмотр, налог (по дате окончания)

## Продвинутые / платные функции

- Генерация «паспорта авто» (PDF/ссылка) с полной историей ТО — для продажи авто
- QR/NFC-метка на авто → быстрый доступ к истории обслуживания
- Прогноз следующего ТО на основе среднего пробега
- Сравнение цен на услуги со средними по рынку/региону
- Мультипользовательский доступ с ролями (владелец сервиса / механики) — CRM-режим для автосервисов
- Учёт склада запчастей (для сервисов)
- Облачная синхронизация между устройствами (подписка)
- Совместный доступ к одному авто (семья)
- Чтение реального пробега через OBD-II Bluetooth / API коннектед-кара (вместо оценки)
- API/интеграции (1С, эквайринг) — enterprise

## Экраны (черновая раскладка)

- Bottom nav: Гараж | Поиск | Отчёты | Профиль
- Гараж — список карточек авто
- Карточка авто — шапка (фото, данные) + табы: История ТО / Документы / Расходы / Напоминания
- Добавление записи об услуге — короткая форма (дата, пробег, тип, стоимость, комментарий, фото)
- Поиск — фильтры сверху + плоский список результатов по всем авто
- Отчёты — период → графики + экспорт

## Нефункциональные требования

- Оффлайн-режим с последующей синхронизацией
- Быстрый ввод записи (минимум тапов)
- Индексация БД под поиск при большом объёме записей
- Безопасность данных клиентов сервиса (шифрование, роли)
- Надёжные бэкапы истории авто
- Масштабируемость бэкенда (Ktor + PostgreSQL)
- Локализация (минимум RU/EN)
- Модель данных с самого начала закладывает роли (владелец/механик/админ сервиса)
