# Car Manager — ТЗ для MVP

Цель MVP: проверить, что приложением реально удобно пользоваться вместо таблицы. Только то, без чего приложение теряет смысл. Всё остальное в разделе «Не в MVP».

Рекомендация: MVP делать **локально** (Room, без бэкенда и аккаунтов). Синхронизация, роли и облако добавляются после проверки идеи. Модель данных сразу проектировать с id-шниками и `updated_at`, чтобы потом не переписывать.

---

## Этап 1. Гараж (авто)

- [ ] Модель `Car`: марка, модель, год, VIN (опц.), госномер (опц.), текущий пробег, фото (опц.)
- [ ] Экран «Гараж»: список карточек авто
- [ ] Добавление авто (форма)
- [ ] Редактирование авто
- [ ] Удаление авто (с подтверждением; вместе с его записями)
- [ ] Пустое состояние экрана («Добавьте первый автомобиль»)

## Этап 2. Записи об обслуживании (ядро приложения)

- [ ] Модель `ServiceRecord`: авто, дата, пробег, тип услуги, стоимость, комментарий
- [ ] Справочник типов услуг: предустановленный список (замена масла, фильтры, тормозные колодки, шины и т.д.)
- [ ] Возможность добавить свой тип услуги
- [ ] Карточка авто: шапка с данными + список записей (новые сверху)
- [ ] Добавление записи: короткая форма, дата = сегодня по умолчанию, пробег подставляется из последнего значения
- [ ] Редактирование записи
- [ ] Удаление записи
- [ ] При добавлении записи с пробегом больше текущего обновлять пробег авто
- [ ] Валидация: пробег не меньше предыдущего (с возможностью подтвердить исключение), стоимость >= 0
- [ ] Прикрепление фото чека к записи (одно-несколько фото)

## Этап 3. Поиск по всем услугам

- [ ] Экран «Поиск» (вкладка в нижней навигации)
- [ ] Текстовый поиск по комментарию и типу услуги
- [ ] Фильтр по авто
- [ ] Фильтр по типу услуги
- [ ] Фильтр по диапазону дат
- [ ] Фильтр по диапазону пробега
- [ ] Результаты: плоский список по всем авто, тап ведёт на запись
- [ ] Индексы в БД по дате, пробегу, типу услуги

## Этап 4. Напоминания (простая версия)

- [ ] Модель правила: авто, тип услуги, `interval_km` и/или `interval_months`
- [ ] Создание правила на карточке авто («Менять масло каждые 10 000 км / 6 мес.»)
- [ ] Расчёт следующего срока: от последней записи этого типа (`due_mileage`, `due_date`)
- [ ] Статусы на карточке авто: ок / скоро / просрочено
- [ ] Push-уведомление по дате
- [ ] Кнопка «Обновить пробег» (один тап, одно поле) на карточке авто
- [ ] Оценка пробега: `last_known + avg_km_per_day * days_since` (по последним 2–3 записям)
- [ ] Уведомление по пробегу по оценке с текстом «уточните пробег» и переходом на быстрый ввод
- [ ] Не гейтить вход в приложение вводом пробега

## Этап 5. Отчёты (минимум)

- [ ] Экран «Отчёты» (вкладка в нижней навигации)
- [ ] Выбор периода и авто (или все авто)
- [ ] Итоговая сумма расходов за период
- [ ] Расходы по типам услуг (список или простая диаграмма)
- [ ] Расходы по месяцам (столбчатая диаграмма)
- [ ] Экспорт записей в CSV

## Этап 6. Общее и полировка

- [ ] Нижняя навигация: Гараж | Поиск | Отчёты | Настройки
- [ ] Настройки: единицы (км/мили), валюта
- [ ] Локальный экспорт/импорт резервной копии (файл), чтобы данные не терялись
- [ ] Локализация RU/EN (строки сразу в ресурсах)
- [ ] Тёмная тема
- [ ] Проверка быстрого ввода: запись услуги за ~20–30 секунд

---

## Критерии готовности MVP

- [ ] Всё работает без интернета
- [ ] Добавить авто и первую запись можно меньше чем за минуту
- [ ] Поиск находит нужную запись среди 1000+ записей без заметной задержки
- [ ] Напоминание приходит вовремя и корректно считается по дате и пробегу
- [ ] Данные не теряются при обновлении приложения (миграции БД)

---

## Не в MVP (на потом)

- Клиентская база и роли для автосервисов
- Прайс-лист и шаблоны услуг
- Запись на приём / календарь
- Учёт склада запчастей
- Хранилище документов (СТС, полис и т.д.), кроме срока действия страховки/техосмотра в напоминаниях
- Паспорт авто (PDF/ссылка для продажи)
- QR/NFC-метка на авто
- Облачная синхронизация и аккаунты, бэкенд (Ktor + PostgreSQL)
- Совместный доступ к авто
- Чтение пробега через OBD-II
- Сравнение цен с рынком, прогнозы
- Учёт топлива
- Подписка и платный тариф

---

## Порядок работы (кратко)

1. Данные и гараж, 2. Записи об услугах, 3. Поиск, 4. Напоминания, 5. Отчёты, 6. Полировка.
После этапа 2 приложением уже можно пользоваться самому. Показывай его реальным людям (владелец авто, знакомый механик) как можно раньше, не дожидаясь этапа 6.
